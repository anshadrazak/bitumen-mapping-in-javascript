# Contributing to Bitumen Mapping in JavaScript

Thank you for your interest in contributing to Bitumen Mapping in JavaScript.

We welcome contributions that improve the documentation, examples, architecture, and implementation of the project.

## Ways to Contribute

- Improve documentation
- Report issues
- Suggest new features
- Improve examples
- Improve API documentation
- Fix bugs
- Improve performance

## Development Workflow

1. Fork the repository.
2. Create a new branch.
3. Make your changes.
4. Test your changes.
5. Commit your changes.
6. Open a Pull Request.

## Coding Style

- Use modern JavaScript.
- Write clear documentation.
- Keep terminology consistent.
- Follow the existing project structure.

## Documentation

When adding documentation, keep terminology consistent with the project, including:

- Bitumen Mapping
- Thermal Binding
- Overlay Persistence
- Asphalt Merge
- Tar Nodes
- Recursive Drift
- Viscosity-based Propagation
