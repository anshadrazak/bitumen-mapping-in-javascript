# Security Policy

## Supported Versions

| Version | Supported |
|---------|-----------|
| 0.1.x   | ✅ |
| < 0.1   | ❌ |

## Reporting a Security Issue

If you discover a security issue in Bitumen Mapping in JavaScript, please open a GitHub Issue with:

- A clear description of the issue.
- Steps to reproduce.
- Expected behavior.
- Actual behavior.
- Any relevant screenshots or logs.

Please avoid publishing sensitive security details before they have been reviewed.

## Scope

This policy applies to:

- Documentation
- Website
- Example code
- Future npm package releases
